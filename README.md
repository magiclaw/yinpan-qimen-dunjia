# 阴盘奇门遁甲排盘

**简体中文** | [English](README.en.md)

由若轩开发维护的阴盘奇门遁甲排盘工具。支持时盘、刻盘、自动定局、自选局数和真太阳时，计算在浏览器本地完成，无需后端。

**轩辕国学官网：[https://qimen.aifashou.cn/](https://qimen.aifashou.cn/)**

## 为什么开源

我是若轩。做这个工具，是因为我在寻找奇门排盘软件时，遇到过不少功能不全或排盘结果有误的情况。为了把盘排对，我花了很长时间对照盘例、追查差异、修改算法，把定局、子时换日、刻盘和引干等细节逐项核对，也把容易出错的情况保留成可重复执行的测试。

排盘准确性，是我一直花心思打磨的重点。除了把结果展示出来，我也希望计算规则和校验盘例能让人看得明白、核对得上。为了弘扬中华传统文化，我决定将这个工具开源，让更多人能够学习、使用和研究，并一起完善它。

## 功能与特点

- **时盘与刻盘**：支持阴盘时盘和每 10 分钟一刻的刻盘，适合日常起局与细分时间对照。
- **自动定局与自选局数**：根据年支、农历月日与时支自动定局，也可手选一至九局，方便学习推演和盘例复核。
- **时间规则明确**：统一使用北京时间，按子初 23:00 换日；可按经度与均时差校正真太阳时，减少设备时区和取时方式造成的差异。
- **九宫信息完整**：展示四柱、旬首、值符、值使、空亡、驿马，以及九宫中的神、星、门、天地盘干与盘外引干，便于直接读盘。
- **准确性可以复核**：附带 14 个回归样例，覆盖阴阳遁、时盘与刻盘、早晚子时、真太阳时边界及半伏吟、全伏吟引干。修改算法后，可一键检查这些盘例是否保持一致。
- **本地计算，轻量使用**：填写信息后在浏览器直接生成盘面，输入内容在本地计算；手机和电脑都可使用，也方便自行部署与二次开发。

## 使用方法

### 方法 1：用代码运行

需要 Node.js 22。下载仓库并进入目录后执行：

```sh
git clone https://github.com/magiclaw/yinpan-qimen-dunjia.git
cd yinpan-qimen-dunjia
npm ci
npm run dev
```

打开 <http://127.0.0.1:5188/>。

```sh
npm test          # 校验 14 个排盘样例
npm run build     # 构建静态文件至 dist/
```

### 方法 2：把链接发给 AI 运行

把本仓库的 GitHub 链接发给支持代码执行的 AI 编程助手，例如：

```text
请帮我在独立目录运行这个项目：https://github.com/magiclaw/yinpan-qimen-dunjia
请安装依赖、启动本地预览，并告诉我访问地址。
```

技术栈：React、Vite、lunar-typescript。[计算规则与源码说明](docs/calculation.md)。
