## 计算规则

- 输入时间统一为北京时间 UTC+8，与访问设备的时区无关。
- 阴盘年支取立春年界，配合农历月、日和时支数自动定局；阴阳遁按节气切换。
- 子初 23:00 换日，中五寄坤。
- 刻盘每 10 分钟一刻，按所选时间所在的整刻计算，按当前排盘规则取时。
- 真太阳时使用输入经度与均时差近似校正，用于修正所选地点的时间。
- 不同流派的年界、换日、定局与寄宫规则可能不同。对照盘例时，请先统一这些设置。

## 源码

| 文件 | 用途 |
| --- | --- |
| `src/pan-engine.js` | 阴盘奇门排盘核心算法 |
| `src/main.jsx` | 信息填写页和结果页 |
| `src/style.css` | 简洁样式与常规九宫布局 |
| `scripts/verify-engine.mjs` | 14 个时盘、刻盘、子时及引干回归样例 |

日历依赖 `lunar-typescript@1.8.6`（MIT），界面使用 React，构建使用 Vite。无需 API 密钥，排盘过程不向服务端提交输入信息。构建产物 `dist/` 可部署到静态托管服务。
